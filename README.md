# Messi Web App

Lionel Messi hakkında basit bir statik web uygulaması.

## İçerik
- **index.html** — Sayfa yapısı
- **style.css** — Tasarım ve stiller
- **script.js** — Kulüp listesi ve rastgele bilgi özelliği

## Çalıştırma
Projeyi klonlayın ve `index.html` dosyasını tarayıcıda açın:

```bash
git clone https://github.com/berkef17/messiwebapp2.git
cd messiwebapp2
```

Ardından `index.html` dosyasına çift tıklayın.

## Özellikler
- Messi biyografisi
- İstatistik kartları (Ballon d'Or, Şampiyonlar Ligi, Dünya Kupası)
- Kariyer kulüpleri listesi
- Rastgele Messi bilgisi gösteren buton
